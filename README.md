# ROS ECU Prototype (v1.3)

Independent personal prototype, June 2025: a ROS-oriented motor-control ECU board, built as a learning and bring-up platform.

This is a personal design and is separate from any employer work.

## Contents
- `Ros_Ecu_v1.3.zip`: 4-layer PCB manufacturing package (Gerbers, drill files, flying-probe test data)
- `ROS_ECU_V1_BOM.xlsx`: bill of materials with LCSC part numbers (JLCPCB-assembly ready)
- `ROS_ECU_V1_CPL.xlsx`: component placement list
